# Bible-webViewer
A simple web app for viewing the Bible in your browser.

# Requirements
A modern web browser with JavaScript enabled.
Bible book data files in .json format, stored in a folder you can select when prompted.

The app’s HTML, CSS, and/or JavaScript files. Current: Bible-webViewer-v1.html

Saving notes: Choosing a local folder depends on browser support for the File System Access API. If that isn’t available, the app can use its fallback options, such as browser storage or downloading and importing notes.
